# Extension Icons

Place the following PNG files in this directory before publishing to the Chrome Web Store:

| File | Size | Usage |
|---|---|---|
| `icon16.png`  | 16×16 px  | Browser toolbar (small) |
| `icon32.png`  | 32×32 px  | Windows taskbar |
| `icon48.png`  | 48×48 px  | Extensions management page |
| `icon128.png` | 128×128 px | Chrome Web Store listing |

## Design guidelines

- Use the FormPilot lightning bolt (⚡) on a **#6366f1** (indigo-500) rounded-square background
- Export as PNG with transparency
- All four sizes must be present for the extension to pass Web Store review

## Temporary placeholder

During development, Chrome will show a blank icon if the PNGs are missing.
The extension still loads and functions normally without them.
